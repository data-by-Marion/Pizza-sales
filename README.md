# Pizza-sales
This is a Pizza data set analyzed in SQL and visualized in Power Bi

**AIM**
To identify the pizza category with the most sales
To summarize the general performance for the restaurant
To advise on wats to improve sales

**Steps taken**
Imported data into SQL
Summarized the data set that is cleaned and analyzed
Imported into Power Bi, visualized and advised the way forward on increasing the sales and profit for the restaurant
